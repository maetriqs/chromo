    Key bindings

    Controls

    Mouse: look and aim. Left click fires, builds or uses the selected item. Hold right click to aim down sights. The mouse wheel cycles slots. Esc pauses.

    Credits

    Squall is an original battle royale built for the Chromo shelf.

    Design, code, island, characters, weapons and HUD by The_headphones.

    Every model is built from code at load time. Every sound is synthesized live with the Web Audio API. There are no third-party art, audio or game assets.

    Rendering by Three.js r128 (MIT licence). Type set in Big Shoulders Display and Atkinson Hyperlegible.
